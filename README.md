# ADL NEXUS

One desk. Three jobs.

| Job | Where | What it does |
| --- | --- | --- |
| Work | Counter | Write, check, draw, and clip. Exact tools run here. The model runs when it can. |
| Sell | Plant and `/shop` | Buyers can pay Atomic Dream Labs on Cash App. You mark an order paid only after you see the money. |
| Build | Lab | Write a page and test it. Hosting it still waits for you. |

You hold COMMIT before a live trade, a hosted page, or anything that spends money.

This repository is the office. It is not the Python ADL-Nexus kernel.

Orders and the desk key are kept in `.data` on the machine that runs the app. A hosted database is used only when `DATABASE_URL` is set.
